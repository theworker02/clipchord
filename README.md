# clipchord

Clip digests and chord fingerprints for local integrity checks.

**Site:** https://theworker02.github.io/clipchord/

## Install / run

```bash
git clone https://github.com/theworker02/clipchord.git
cd clipchord
node src/cli.js
node --test
```
